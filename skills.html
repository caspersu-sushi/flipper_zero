我做的 Claude skill。下載 zip 後上傳到 Claude 就能使用。

> pdf-shelf-viewer

描述：上傳 PDF、PPT 或 Word 講義，自動做成一個講義瀏覽頁面，點左邊的檔案就能在右邊切換觀看。

  • PPT、Word 自動轉成 PDF，保留原本的版面和圖片
  • 從第一頁讀出真正的標題，依課程分組並標示頁數
  • 可以跳頁、縮放，手機上也能用
Status: Completed | Version: 0.1
安裝步驟
  1. 到 Claude 的 Settings → Capabilities，打開「Code execution and file creation」（新版叫「Create and edit files」）。
  2. 按右邊的「下載 .zip」，不用解壓縮。
  3. 到 Customize → Skills，按「+」→「+ Create skill」→「Upload a skill」，選這個 zip。
  4. 開新聊天，上傳 PDF 或 PPT，說「幫我做成講義瀏覽器」。
